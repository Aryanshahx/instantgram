# InstantGram 📸

An Instagram-like app built with **Flutter**.

## Stack
| Part | Service |
|---|---|
| Mobile app | Flutter (Android) |
| APK builds | GitHub Actions |
| Auth + Database | Firebase Auth + Cloud Firestore |
| Backend API | Vercel (coming soon) |
| Media storage | Tigris (coming soon) |

## Download the APK
- **Every push to `main`** → Actions tab → latest run → *Artifacts* → `InstantGram-apk-N`
- **Releases** → push a tag like `v0.1.0` → APK appears under *Releases*

## Project structure
```
lib/
├── main.dart
├── app.dart
├── core/        # theme, constants, network, utils
├── features/    # auth, feed, post, profile, search, reels, notifications
└── shared/      # reusable widgets
```

## Firebase
- `lib/firebase_options.dart` and `android/app/google-services.json` are generated by `flutterfire configure`
  (safe to commit — they are app identifiers, not secrets).
- Security rules: `firestore.rules` (paste in Firebase Console → Firestore → Rules).
